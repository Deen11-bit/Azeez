Engineering Unit Converter

What it does

The Engineering Unit Converter is a Python program designed to convert different engineering measurements from one unit to another.

It converts millimetres to inches, inches to millimetres, Celsius to Fahrenheit, Fahrenheit to Celsius, kilograms to pounds, pounds to kilograms, km/h to m/s, and m/s to km/h.

How to run it

1. Install Python 3.
2. Download or clone this project from GitHub.
3. Open the project folder.
4. Run the following command:

python engineering_converter.py
